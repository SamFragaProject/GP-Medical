## ⚡ RESUMEN ULTRA-RÁPIDO

Si ya sabes lo básico:

### Primera Vez:
```bash
1. Abrir VSCode en carpeta GP-Medical
2. Abrir Terminal (Ctrl+Ñ)
3. cd frontend
4. npm install
5. npm run dev
6. Ir a: http://localhost:3000
```

### Días Siguientes:
```bash
1. Abrir VSCode
2. Terminal: cd frontend
3. Terminal: npm run dev
4. Ir a: http://localhost:3000
```
