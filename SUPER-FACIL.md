## PASO 1: ¿Tienes Este Programa?

### El programa se llama: **Node.js**

¿Qué es? Es como cuando instalas WhatsApp para que funcione. Sin WhatsApp no puedes chatear. Sin Node.js tu proyecto no funciona.

### ¿Cómo saber si lo tengo?

**Windows:**
1. Presionar tecla Windows
2. Escribir: "cmd"
3. Presionar Enter
4. Se abre una ventana negra
5. Escribir: `node --version`
6. Presionar Enter

**¿Qué debería pasar?**
- ✅ Si sale algo como "v18.0.0" → Ya lo tienes, pasa al PASO 2
- ❌ Si dice "no se reconoce" → No lo tienes, sigue abajo

### ¿Cómo lo instalo?

1. Ir a: **https://nodejs.org**
2. Verás 2 botones verdes
3. Click en el que dice **"LTS"** (el de la izquierda)
4. Se descarga un archivo
5. Doble click en ese archivo
6. Click en "Siguiente" varias veces
7. Esperar a que termine
8. **Reiniciar tu computadora**
9. Listo

---

## PASO 2: Abrir Tu Proyecto

### 2.1 Buscar la Carpeta

Busca en tu computadora una carpeta que se llame: **GP-Medical**

(Probablemente en Documentos o Descargas)

### 2.2 Abrir VSCode

**¿Qué es VSCode?** Es como Word, pero para código. Es donde verás y editarás tu proyecto.

**¿No lo tienes?**
1. Ir a: https://code.visualstudio.com
2. Descargar
3. Instalar (siguiente, siguiente, siguiente)

### 2.3 Abrir la Carpeta en VSCode

**Opción A (Más fácil):**
1. Click DERECHO en la carpeta GP-Medical
2. Buscar: "Abrir con Code"
3. Click ahí

**Opción B:**
1. Abrir VSCode (ícono azul)
2. Menú Archivo → Abrir Carpeta
3. Buscar GP-Medical
4. Click en "Seleccionar carpeta"

✅ Ahora verás una lista de archivos en el lado izquierdo

---

## PASO 3: Abrir la "Ventana de Comandos"

**¿Qué es esto?** Es como cuando usas "Ejecutar" en Windows, pero dentro de VSCode. Es donde escribirás los 3 comandos.

### Cómo abrirla:

En VSCode, ir al menú de arriba:
**Terminal → Nueva Terminal**

O presionar: **Ctrl + ñ** (la tecla de la eñe)

Aparecerá una **ventana azul o negra** en la parte de abajo.

---

## PASO 4: Escribir 3 Comandos

### ⚠️ IMPORTANTE:
- Escribe un comando
- Presiona Enter
- Espera a que termine
- Luego escribe el siguiente

### Comando 1: Ir a la Carpeta Correcta

**Escribir EXACTAMENTE esto:**
```
cd frontend
```

**Presionar:** Enter

**¿Qué pasó?** Entraste a la carpeta "frontend" (como cuando haces doble click en una carpeta)

---

### Comando 2: Descargar las Herramientas (Solo Primera Vez)

**Escribir EXACTAMENTE esto:**
```
npm install
```

**Presionar:** Enter

**¿Qué pasará?**
- Verás MUCHAS líneas de texto
- Va a tardar **2-3 minutos**
- Es como cuando instalas una app en el celular
- Solo lo haces UNA VEZ

**Espera** hasta que pare de escribir cosas y veas el cursor parpadeando de nuevo.

---

### Comando 3: Encender el Proyecto

**Escribir EXACTAMENTE esto:**
```
npm run dev
```

**Presionar:** Enter

**¿Qué pasará?**
Verás algo como:
```
Local: http://localhost:3000
Ready in 3.2s
```

✅ **¡PERFECTO!** El proyecto está encendido.

**IMPORTANTE:** NO CIERRES esta ventana. Déjala abierta.

---

## PASO 5: Ver Tu Proyecto

### Abrir el Navegador

1. Abrir Chrome, Edge o Firefox
2. En la barra de arriba (donde escribes google.com), escribir:
   ```
   localhost:3000
   ```
3. Presionar Enter

✅ **¡LISTO!** Deberías ver tu proyecto.

---

## 🎨 Hacer Cambios

### Para Cambiar Algo:

1. **En VSCode**, lado izquierdo, buscar:
   ```
   frontend → src → app → page.tsx
   ```
   (Click, click, click en cada carpeta)

2. **Click** en el archivo `page.tsx`

3. **Cambiar** algún texto que veas

4. **Guardar:** Presionar `Ctrl + S`

5. **Ir al navegador** donde está tu proyecto

6. **Refrescar:** Presionar `F5`

✅ **¡Verás tu cambio!**

---

## 🛑 Apagar Cuando Termines

1. Ir a VSCode
2. En la ventana negra/azul de abajo
3. Presionar: **Ctrl + C**
4. Puede que pregunte algo, presionar: **Y**
5. Listo

---

## 🔄 Mañana, Para Volver a Trabajar

Solo necesitas 2 comandos:

1. Abrir VSCode en la carpeta GP-Medical
2. Abrir Terminal (Ctrl + ñ)
3. Escribir: `cd frontend`
4. Escribir: `npm run dev`
5. Abrir navegador: `localhost:3000`

## ❓ Preguntas en Lenguaje Simple

### "¿Qué es localhost:3000?"

Es como una dirección de internet, pero en tu computadora. Como "google.com" pero local.

### "¿Por qué tantos pasos?"

La primera vez es más largo porque hay que instalar cosas. Los días siguientes son solo 2 comandos.

### "¿Puedo romper algo?"

No. No puedes romper nada. Lo peor que puede pasar es que tengas que volver a escribir los comandos.

### "¿Necesito internet?"

- Para instalar Node.js: Sí
- Para instalar las herramientas (npm install): Sí
- Para trabajar después: No
